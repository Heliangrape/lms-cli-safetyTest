# lms-cli v0.4.2

## 修复与改进

- 修复 Blackboard 待办查询日期跨度过大时的接口错误：按最多 15 天的窗口请求真实待办接口，去重后合并；不以日历事件或空数据替代失败结果。
- 新增**实验性**记住密码和自动登录，默认关闭。登录仍使用各学校自己的页面及 SSO 跳转，不替换为统一密码页。
- 支持常见表单、分步账号／密码、精确匹配的 HTTPS 跨域提交，以及 PolyU 使用的 Microsoft ADFS 脚本式登录按钮；不保证所有学校兼容。
- 记住密码只填充，由用户点击登录；自动登录填充后等待 2 秒再提交。可取消勾选、点击取消、按 Esc 或关闭窗口停止后续自动操作。
- 账号密码仅在学校身份验证成功后在本机加密保存。按学校/账号及平台隔离应用登录分区；支持用户主动通过私密 stdin 导入 TOTP 密钥。

## 安装与更新

推荐使用自包含 CLI 安装包；已经安装的用户可运行 `lms update`，确认后更新。程序更新保留学校配置、凭据和本地待办。独立授权 App 是可选附件，不是 CLI 使用的前置步骤。

请下载与操作系统和 CPU 架构匹配的附件，并使用同一 Release 的 `SHA256SUMS.txt` 核对文件完整性。学校额外要求的 CAPTCHA、推送 MFA 和设备合规检查仍需用户完成；本版本不绕过学校验证或保证永久免登录。

## 验证范围

发布前检查包括类型检查、97 项自动化测试、四组离线 Electron 登录验收，以及目标系统的构建和隔离安装检查。真实学校兼容范围以 `docs/VALIDATION.md` 为准；合成表单测试通过不等于所有学校已验收。
